# NCP-AII 刷题模拟考

一个单文件的 NVIDIA NCP-AII 刷题网页：题库 223 题（DC Lab Sim 原站 208 题 + 15 道自编多选），
每次随机抽 **75 题**、限时 **80 分钟**、**85% 及格**，题干与选项都会重新打乱。

## 怎么用

- 电脑：双击 `index.html`，或直接访问部署后的网址。
- 手机：打开网址 → 浏览器菜单里「添加到主屏幕」，用起来跟 App 一样。
- 完全离线：整个程序只有 `index.html` 一个文件，不联网、不加载任何外部资源。

## 功能

| 功能 | 说明 |
|---|---|
| 模拟考试 | 75 题 / 80 分钟，固定含 4 道多选，到点自动交卷 |
| 判分 | 正确率 + 85% 及格线（75 题需答对 64 题）+ 按考纲域统计 |
| 错题本 | 答错自动入库并计数，答对一次即移出，可单独重练 |
| 快速练习 | 20 题，选完立刻判对错并给中英解析 |
| 断点续考 | 考到一半刷新/关页面，重开会问你是否继续，剩余时间接着走 |
| 数据迁移 | 「导出文件 / 导入文件」或「复制数据 / 粘贴导入」 |

## 数据存在哪里

答题记录保存在**当前浏览器**的 localStorage 里，按网址区分：

- 换手机、换网址、清缓存之后记录不会自动跟过来；
- 先在旧地址点「复制数据」，到新地址点「粘贴导入」即可搬一次；
- 隐私模式或无痕窗口里打开，记录不会保存（页面顶部会提示）。

## 部署到 GitHub Pages

1. 新建仓库（Public），把本目录的 `index.html` 上传上去（网页端直接拖拽即可）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save。
3. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 题库来源与免责

- 题目抓取自 <https://www.dclabsim.com/> 前端内嵌题库（208 道单选），版权归原作者 Sean Boerhout 及站点所有。
- 15 道多选题、中文译文与页面代码为本项目整理，仅供个人复习使用，请勿用于商业分发。
- 译文由 AI 翻译整理，命令、参数、XID 码等关键信息请以英文原文与 NVIDIA 官方文档为准。
- 注意：原题库正确选项有 74.5% 是 B，程序已把选项打乱，不要依赖该规律。
