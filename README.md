# NCP-AII 刷题模拟考

一个单文件的 NVIDIA NCP-AII 刷题网页：题库 **273 题**，每次随机抽 **75 题**、限时 **80 分钟**、**85% 及格**，题干与选项都会重新打乱。

## 题库构成

| 来源 | 题数 | 说明 |
|---|---|---|
| DC Lab Sim 原站题库 | 208 | 命令、输出判读、XID 排障为主 |
| 自编题 | 15 | 覆盖 ECC/XID/DCGM/enroot/Slurm/机架/RoCE 等 2~3 个正确项 |
| **NVIDIA 官方练习测试** | **50** | 取自 NVIDIA 认证页的 practice test（场景题，附逐选项解析与官方文档链接） |

其中**多选题共 18 道**：15 道自编多选，外加 3 道由原先「两个选项都正确、却只标了一个」的单选改写而来（`tm-clus-002`、`tm-clus-020`、`tm-bmc-004`）。

首页可以切换练习范围：**全部 273 / DC Lab 223 / 官方样题 50**。

## 怎么用

- 电脑：双击 `index.html`，或直接访问部署后的网址。
- 手机：打开网址 → 浏览器菜单里「添加到主屏幕」，用起来跟 App 一样。
- 完全离线：整个程序只有 `index.html` 一个文件，不联网、不加载任何外部资源。

## 功能

| 功能 | 说明 |
|---|---|
| 模拟考试 | 75 题 / 80 分钟，固定含 4 道多选，到点自动交卷 |
| 判分 | 正确率 + 85% 及格线（75 题需答对 64 题）+ 按考纲域统计 |
| 错题本 | 答错自动入库并计数，答对一次即移出，可单独重练 |
| **错题重做** | 错题本里每题直接给选项：单选即时判定，多选勾选后确认；可「再答一次」反复练 |
| 快速练习 | 20 题，选完立刻判对错并给中英解析 |
| 断点续考 | 考到一半刷新/关页面，重开会问你是否继续，剩余时间接着走 |
| 数据迁移 | 「导出文件 / 导入文件」或「复制数据 / 粘贴导入」 |

## 题库准确性

题库来自二手来源，**不是** NVIDIA 官方题库，因此按主题分批做过核对。现状：

| 范围 | 状态 |
|---|---|
| NVIDIA 官方样题（50 道） | 自带逐项解析与官方链接，未改动 |
| XID 错误码类（约 49 道） | ✅ 已按 NVIDIA Xid Errors Catalog（v620）逐条核对，修正 34 道 |
| DCGM / `nvidia-smi` 命令与参数（约 29 道） | ✅ 已按 nvidia-smi man page 与 DCGM 官方文档核对，修正 7 道 |
| InfiniBand（`ibstat`/`perfquery`/`ibdiagnet`/`iblinkinfo`，26 道） | ⬜ 尚未逐条核对 |
| Slurm（`sinfo`/`squeue`/`scontrol`/`sacct`，26 道） | ⬜ 尚未逐条核对 |
| 容器（Docker / Enroot / Pyxis，27 道） | ⬜ 尚未逐条核对 |
| 其余（`ipmitool`/`dmidecode`/`sensors`/`nvsm`/`gpu-burn`/`nvtop`/`nvidia-bug-report` 等） | 部分核对 |

> 上表按主题统计，**不是互斥分类**：XID 题里也包含 `nvidia-smi`、`dcgmi` 命令题，会在两行里各计一次。


带 `ref` 字段的题，解析底部会显示官方文档链接，可点开核对。**做错时以链接里的官方文档为准，不要以题库解析为准。**

已知被改写过的典型错误，供判断二手题库的可信度参考：

- `XID 76/77/78` 曾被说成 NVLink 相关，实际 76/77 是 CE7/CE8 拷贝引擎错误、78 是 vGPU 启动错误；只有 `XID 74` 是 NVLink（且仅 A100/H100）
- `XID 54` 曾被说成「看门狗超时」，实际是「辅助电源未连接到 GPU 板卡」
- `XID 43` 曾被说成「GPU 停止响应、需换卡」，实际是应用软件故障被终止、**GPU 仍健康**
- `nvidia-smi --pm` / `--mig` 这两个长参数不存在，官方是 `-pm` / `-mig`
- `dcgmi diag` 是**四级**（r1–r4）不是三级，`-r 4` 才包含 memtest
- DCGM field 150/155/203 分别是**温度/功耗/利用率**，`DCGM_FI_PROF_SM_ACTIVE` 是 **1002**

## 数据存在哪里

答题记录保存在**当前浏览器**的 localStorage 里，按网址区分：

- 换手机、换网址、清缓存之后记录不会自动跟过来；
- 先在旧地址点「复制数据」，到新地址点「粘贴导入」即可搬一次；
- 隐私模式或无痕窗口里打开，记录不会保存（页面顶部会提示）。

## 部署到 GitHub Pages

1. 仓库里上传或覆盖 `index.html`。
2. Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save。
3. 等 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 两个关于“答案规律”的提醒

- DC Lab Sim 题库的正确选项仍有 **71.3% 是 B**；NVIDIA 官方样题的 50 道里，正确项**全部排在 A**。两者都是源数据的排版习惯，程序已把选项逐题打乱，不要据此押答案。
- 官方样题是“教学版”样例，覆盖的是考纲骨架，不等于真实考题全集。
